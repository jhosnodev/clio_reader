          04 — verifyoptional, recommended
        

        

          

            

              Check that the file you got is the file that was published.
            

            

              Download SHA256SUMS.txt into the same folder as the file, then run
              the command for your system. If the hash matches, the file is intact.
            

          

          

            

              

                linux
              

              
sha256sum -c SHA256SUMS.txt --ignore-missing

            

            

              

                windows · powershell
              

              
Get-FileHash .\Clio-Reader-Setup.exe -Algorithm SHA256

            

            

              On Windows, compare the hash it prints with the line for the same file in
              SHA256SUMS.txt.
