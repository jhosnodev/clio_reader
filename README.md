# echo_reader

Biblioteca local multiplataforma para leer EPUB, PDF y CBZ. El MVP prioriza Windows y Android, funciona sin conexión y no incluye perfiles, backend ni sincronización en la nube.

La documentación del proyecto se encuentra en [`documentation/`](./documentation/).

- [`01-definicion-mvp.md`](./documentation/01-definicion-mvp.md): alcance y criterios del MVP.
- [`02-arquitectura-tecnica.md`](./documentation/02-arquitectura-tecnica.md): arquitectura, capas y patrones.
- [`03-arquitectura-data-y-metadata.md`](./documentation/03-arquitectura-data-y-metadata.md): datos locales, metadata, progreso, settings, marcadores y notas.
- [`04-features-futuros.md`](./documentation/04-features-futuros.md): índice de capacidades fuera del MVP.
- [`documentation/features/`](./documentation/features/): especificaciones de features futuras.
